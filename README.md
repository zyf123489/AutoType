# 逐字输入

逐字输入是一个 Windows 本地 GUI 工具。它将编辑框中的文字逐字符输入到当前焦点窗口，不使用系统剪贴板，也不读写远程主机文件。

## 安装和运行

需要 Python 3.10 或更高版本。

```powershell
pip install -r requirements.txt
python main.py
```

## 使用方法

1. 在文本框中粘贴或编辑文字、中文和符号。
2. 确认本地输入法已切换为英文。
3. 设置字符间隔，默认 `150 ms`，允许范围为 `50-500 ms`；按目标输入框的规则设置“换行键”。
4. 按全局热键 `Ctrl+Alt+S`，或点击“开始输入”。
5. 在 3 秒倒计时内，将焦点切换到堡垒机或远程终端输入框。
6. 暂停或继续输入按 `Ctrl+Alt+P`。
7. 紧急停止按 `Ctrl+Alt+Q`、再次按启动热键，或将鼠标快速移动到屏幕左上角。

倒计时期间再次按启动热键会取消任务。正式输入期间再次按启动热键会立即停止，不会从暂停位置继续；需要重新触发任务。制表符会转换为 `Tab`。ASCII 字符使用模拟键盘按键；汉字、中文标点和其他 Unicode 字符通过 Windows Unicode 键盘事件逐个输入，不使用剪贴板。目标程序必须支持这类事件；部分堡垒机、远程终端或只接收物理按键的输入框可能无法识别，建议先用一小段含中文和符号的文本测试。

## 换行键

文本中的每个换行都会按“换行键”设置输出。默认是 `Enter`；聊天框中可以按目标软件的规则选 `Ctrl+Enter`、`Shift+Enter`、`Alt+Enter`，也可以输入这些修饰键与 `Enter` 的组合，例如 `Ctrl+Shift+Enter`。目标软件决定哪个组合是换行、哪个组合是发送，使用前先在目标输入框手动试一次。程序只输入文本，不会在末尾额外按一次发送键。

## 安全热键

- `Ctrl+Alt+S`：开始；倒计时期间取消；输入期间立即停止。
- `Ctrl+Alt+P`：暂停或继续当前输入。
- `Ctrl+Alt+Q`：任何时候请求紧急停止。
- 鼠标左上角：触发 PyAutoGUI 故障保护并停止输入。

暂停和紧急停止热键是固定的，避免修改启动热键后找不到停止方式。启动热键不能设置成与这两个安全热键相同。

## 修改全局热键

在“修改热键”中输入 `keyboard` 库支持的组合，例如 `ctrl+alt+d`，然后点击“应用热键”。热键配置仅在本次运行中有效，重新启动后恢复为 `ctrl+alt+s`。

## 打包 EXE

先安装项目依赖和 PyInstaller：

```powershell
pip install -r requirements.txt
pip install pyinstaller
```

双击 `build.bat`，或在命令行运行：

```powershell
.\build.bat
```

生成文件位于 `dist\AutoType.exe`。`-w` 禁止显示控制台窗口，`-F` 生成单文件 EXE。运行全局热键通常不需要管理员权限；如果目标程序以管理员身份运行，Windows 的权限隔离可能阻止普通权限程序向它发送按键，此时两者需要使用相同权限级别。

## 安全提示

- 自动化操作堡垒机可能触发平台审计告警，请先确认业务安全规范。
- 英文和半角符号仍由模拟键盘按键输入；请切换为英文输入法，避免输入法拦截。
- 开始前应再次确认当前焦点窗口。发现焦点错误时立即按 `Ctrl+Alt+Q`。
- 网页终端丢字符时，应提高字符间隔。
- 生产环境优先使用 `SELECT` 测试，谨慎处理 `UPDATE` 和 `DELETE`。
- 模拟输入只负责敲入文本；文本中的换行可能触发目标软件的发送、提交或执行动作，请按目标软件规则设置换行键。
